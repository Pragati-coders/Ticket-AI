To build a production-ready enterprise SaaS application called TicketAI.

This project is NOT a CURD tutorial Full-stack Deployed CI/CD.

It must be production quality and portfolio worthy for FAANG, product companies, startups and mid-size companies in 2026.

Tech Stack

• Next.js 15 App Router
• TypeScript
• PostgreSQL
• Prisma 7
• Clerk Authentication
• Supabase Storage
• Tailwind CSS v4
• Shadcn UI
• React Hook Form
• Zod
• Arcjet
• Vercel

Project Rules

• Modular architecture
• Server Actions wherever appropriate
• No duplicated code
• Repository pattern
• Service Layer
• Feature folders
• Strict TypeScript
• Proper Error Handling
• Reusable Components
• Mobile Responsive
• Accessible UI
• Dark and Light Mode
